# 🌐 Personal Portfolio Website

This is my personal portfolio website created as Task 1 of my Web Development Internship.

## 📖 About the Project

The purpose of this project is to create a simple and professional portfolio website using basic web development technologies. It showcases my skills, projects, and contact information.

This project helped me understand how to structure and style a real website.

## 🛠 Technologies Used

- HTML5 – For creating the structure of the website
- CSS3 – For styling, layout, and design
- Google Fonts – For better typography

No external frameworks were used in this project. The main focus was to strengthen my fundamentals.

## 📂 Website Sections

- Home Section – Introduction and role
- Skills Section – Skills displayed in tag format
- Projects Section – Project titles and descriptions
- Resume Section – Downloadable resume
- Contact Section – Contact details

## 🎯 Learning Outcome

Through this project, I improved my understanding of:

- Website structure using HTML
- Styling and layout using CSS
- Creating a clean and readable design
- Organizing content professionally

## 🚀 Future Improvements

- Make the website fully responsive for all devices
- Add more projects
- Improve design with animations
