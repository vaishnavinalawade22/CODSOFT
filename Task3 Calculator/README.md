## 📌 Project Description

This project is a simple and responsive Calculator created using HTML, CSS, and JavaScript.  
It performs basic arithmetic operations like:

- Addition (+)  
- Subtraction (−)  
- Multiplication (×)  
- Division (÷)  

The main purpose of this project was to understand how JavaScript handles user input, conditions, and DOM manipulation.

---

## 🎯 Objectives of the Project

- To build an interactive calculator interface  
- To understand how button click events work  
- To use if-else conditions for performing operations  
- To apply CSS Grid for proper button alignment  
- To make the calculator responsive  

---

## 🛠️ Technologies Used

- HTML → For creating the structure  
- CSS → For styling and responsiveness  
- JavaScript → For calculation logic  

---

## ⚙️ Features

- Responsive design (works on mobile and desktop)  
- Displays complete expression (example: 25 + 5)  
- Prevents division by zero  
- Clean and user-friendly interface  
- Attractive background with soft glass effect  

---

## 🧠 How It Works

1. The first number is stored when the user types.
2. When an operator button is clicked, the operator is stored.
3. The second number is entered after selecting the operator.
4. When "=" is pressed, JavaScript checks the operator using if-else conditions.
5. The result is calculated and displayed on the screen.
